# Spectrumm

# Requirements

--All applications must be developed and tested on Linux (Ubuntu 22.04 or later).

--GUI applications must be developed using PyQt5.

--Follow good coding practices with proper code organization and documentation.

--Handle exceptions and invalid inputs gracefully.

--Include appropriate comments and meaningful variable/function names.

--Provide a README.md explaining how to build and run the applications.

--Test all applications before submission.

--Use the provided/reference spectrum data where applicable.

# Technologies & Platforms

Operating System : Ubuntu 22.04 or later
GUI              : PyQt5
C Compiler       : GCC
Visualization    : PyQtGraph
Numerical Tools  : NumPy / SciPy
Communication    : Linux Shared Memory
